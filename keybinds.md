# Hyprland Keybinds

`mainMod` is `SUPER`.

| Keybind | Action |
| --- | --- |
| `SUPER + Return` | Open Ghostty terminal |
| `SUPER + C` | Close the focused window |
| `SUPER + Q` | Close the focused window |
| `SUPER + M` | Exit Hyprland |
| `SUPER + E` | Open Nemo file manager |
| `SUPER + V` | Toggle floating mode for the focused window |
| `SUPER + SHIFT + V` | Open the last 30 clipboard entries and copy the selected one |
| `SUPER + Space` | Open Wofi application launcher |
| `SUPER + R` | Open Wofi application launcher |
| `SUPER + P` | Toggle pseudo-tiled mode |
| `SUPER + T` | Toggle the dwindle split layout |
| `SUPER + F` | Toggle fullscreen |
| `SUPER + SHIFT + L` | Lock the screen with Hyprlock |
| `SUPER + SHIFT + Q` | Open the Wlogout power menu |
| `SUPER + ALT + S` | Suspend the machine |
| `SUPER + ALT + H` | Hibernate the machine |
| `SUPER + ALT + SHIFT + S` | Power off the machine |
| `SUPER + SHIFT + B` | Toggle Waybar |
| `SUPER + backslash` | Run the standard layout script |
| `SUPER + SHIFT + backslash` | Run the alternate layout script |
| `SUPER + period` | Open the emoji picker |
| `SUPER + Left` | Focus the window to the left |
| `SUPER + Right` | Focus the window to the right |
| `SUPER + Up` | Focus the window above |
| `SUPER + Down` | Focus the window below |
| `SUPER + Tab` | Focus the next window and maximize it within the layout |
| `SUPER + SHIFT + Tab` | Focus the previous window and maximize it within the layout |
| `SUPER + CTRL + Arrow keys` | Resize the focused tiled window by 20 pixels |
| `SUPER + H` | Focus the window to the left |
| `SUPER + K` | Focus the window above |
| `SUPER + J` | Focus the window below |
| `SUPER + L` | Focus the window to the right |
| `SUPER + S` | Take a screenshot of DP-1 and copy it to the clipboard/history |
| `SUPER + SHIFT + S` | Select an area, take a screenshot, and copy it to the clipboard/history |
| `SUPER + SHIFT + CTRL + B` | Toggle compact mode with no borders, gaps, or radius |
| `SUPER + SHIFT + CTRL + A` | Toggle animations |
| `SUPER + mouse wheel down` | Focus the next existing workspace |
| `SUPER + mouse wheel up` | Focus the previous existing workspace |
| `SUPER + left click` | Move the focused window |
| `SUPER + right click` | Resize the focused window |
| `XF86AudioMute` | Toggle output mute |
| `XF86AudioLowerVolume` | Decrease output volume by 5% |
| `XF86AudioRaiseVolume` | Increase output volume by 5% |
| `XF86MonBrightnessDown` | Decrease brightness by 5% |
| `XF86MonBrightnessUp` | Increase brightness by 5% |
